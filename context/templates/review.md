# 독립 리뷰

기능 폴더의 review.md에 사용한다. 새 컨텍스트 리뷰어는 읽기 전용으로 검토한다.

## 인계 자료
- 이슈 URL·번호 또는 요청 위치:
- 승인 계획·승인 범위:
- 관련 설계·규칙:
- 기준 커밋 / 검토 대상 커밋:
- 미커밋 변경과 새 파일 목록:
- 실제 diff·코드·테스트 위치:
- 검증 명령·결과·미실행 항목:
- 리뷰어 / 새 컨텍스트 여부 / 세션 ID 또는 시작 시각:

전체 구현 대화와 구현자의 성공 주장을 검토 근거로 대신하지 않는다.
일반 git diff만으로 새 파일이 포함됐다고 판단하지 않는다.

요구사항 누락, 경계값, 접근 제어, 동시성, 회귀, 잘못된 테스트 단언을 해당 범위에서 검사한다.
발견 사항 없음은 실제 검토 후에만 기록한다.
지적 전 호출부·주변 코드·기존 방어·테스트를 확인하고 구체적인 입력·상태·잘못된 결과를 적는다.
심각한 결함은 기존 방어가 막지 못하는 이유도 제시한다.
개인적 스타일 선호나 근거 없는 가정을 차단 결함으로 올리지 않는다.
동시성 문제는 재현 실행뿐 아니라 구체적인 호출 순서와 상태 변화로도 근거를 제시할 수 있다.
불확실한 위험은 확인 필요로 구분한다. 보안 위험을 근거 없이 안전하다고 낮춰 판단하지 않는다.
깨끗한 변경은 발견 사항 0건으로 통과할 수 있다.

## 직접 확인과 한계
리뷰어가 직접 실행한 명령·결과와 구현자가 제출한 증거를 구분한다.
검토하지 못한 범위와 그 이유를 적는다.

## 최종 판정
미실행 / 통과 / 수정 필요 / 검증 보류 중 하나를 적는다.
차단 결함과 필수 검증 누락이 남으면 통과로 표시하지 않는다.
판정 대상 소스를 식별하고 이후 정확성 변경은 재검토한다.
