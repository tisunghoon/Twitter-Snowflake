# F-03 독립 리뷰

상태: 미실행입니다. 검토할 구현 diff가 아직 없습니다.

## 리뷰 대상
승인 계획·기준 커밋·최종 diff·새 파일·리뷰 세션 식별 정보는 검토 시 기록합니다.
[리뷰 템플릿](../../templates/review.md)을 적용하고 메인 담당의 대화 이력을 상속하지 않습니다.

## 발견 사항과 수정
아직 검토하지 않았습니다. 발견 사항 0건으로 통과했다는 뜻이 아닙니다.
심각도·파일/줄·구체적 근거·기대 동작·차단 여부와 수정·재검증 결과를 연결합니다.

## 최종 판정
미실행입니다. 구현·필수 검증·독립 리뷰가 끝나기 전에 기능 완료로 표시하지 않습니다.
