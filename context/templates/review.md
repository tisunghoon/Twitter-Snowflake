# 독립 리뷰

기능 폴더의 review.md에 사용한다. 새 컨텍스트 리뷰어는 읽기 전용으로 검토한다.

## 인계 자료
- 이슈 URL·번호 또는 요청 위치:
- 승인 계획·승인 범위:
- 관련 설계·규칙:
- 기준 커밋 / 검토 대상 커밋:
- 미커밋 변경과 새 파일 목록:
- 실제 diff·코드·테스트 위치:
- 검증 명령·결과·미실행 항목:
- 리뷰어 / 새 컨텍스트 여부:

전체 구현 대화와 구현자의 성공 주장을 검토 근거로 대신하지 않는다.
일반 git diff만으로 새 파일이 포함됐다고 판단하지 않는다.

## 직접 확인과 한계

검토하지 못한 범위와 그 이유를 적는다.

## 최종 판정
미실행 / 통과 / 수정 필요 / 검증 보류 중 하나를 적는다.
차단 결함과 필수 검증 누락이 남으면 통과로 표시하지 않는다.
판정 대상 소스를 식별하고 이후 정확성 변경은 재검토한다.
