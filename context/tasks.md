# Agy 작업 분해 초안 — 아직 구현 착수 전

기준: [설계 v0.1](design.md), [결정 기록](decisions.md), [개념 노트](concepts.md).
모든 구현 task는 D-02~07 제안 확인 전 차단 상태다. 이는 실행 지시가 아니라 설계 검토용 작업 분해다.
의존 순서: T-01 → T-02 → T-03 → T-04 → T-05 → T-06.
승인 후 정확한 파일·실행 명령·테스트 작업 단위로 인계안을 구체화한다.

| ID / 담당 | 작업과 책임 범위 | 완료·검증 조건 | 학습 활동 |
|---|---|---|---|
| T-01 / 구현 Agy | 환경·Wrapper·Spring Boot·worker 설정과 Clock Bean | Java 21로 test 실행, 올바른 worker 시작 성공·누락/범위 오류 시작 실패. DB·UI 제외 | 워커 설정을 바꿔 시작하기 |
| T-02 / 구현 Agy | core 생성/복원·비트 상수·도메인 오류·상태 전이 | design.md의 결정적 경계 사례 모두 통과; 실패 전후 상태와 회복 확인 | 생성된 ID 필드를 손으로 복원 |
| T-03 / 구현 Agy | POST /api/ids·DTO·예외 변환 | 성공 응답 id 문자열·필드 일치, 각 도메인 오류 503 code; 임의 예외 은폐 없음 | 정상 발급 응답 해석 |
| T-04 / 구현 Agy | 동시성·다중 워커·회귀 테스트 | 설계의 2048회/4096개 집합 기준, 모든 Future 성공 확인, 종료 제한; 실제 sleep 제외 | 잠금이 없을 때의 위험 설명 |
| T-05 / 구현 Agy | 실행 안내·두 프로세스 예시·검토 인계 | 정확한 JVM·명령·포트·서로 다른 worker로 실행 증거; 전체 테스트 결과·커밋/diff·제한 보고 | 두 워커 ID 비교, 재시작 한계 설명 |
| T-06 / Codex | 최종 코드·테스트 리뷰와 직접 검증 | 확정 설계 대조·관련 테스트 실행, 발견 사항 위치/근거 기록, 수정 후 재검증 | 테스트가 보장하는 범위 설명 |

예정 명령은 Wrapper 생성 후 `./gradlew test` 및 `./gradlew bootRun`이며 아직 실행 가능하지 않다.
상세 실행 옵션은 확정된 build와 설정에서 도출한다. 실행 결과를 꾸며 기록하지 않는다.
수정이 필요하면 구현 Agy가 수정하고 T-06을 다시 수행한다. 질문 Agy는 학습 활동을 지원한다.
