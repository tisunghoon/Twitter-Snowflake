# 기능별 작업 목록

기존 T-01~06의 계층별 작업 분해를 기능별 F-01~04로 대체한다.
메인 에이전트 하나가 각 기능의 계획·구현·자체 검증·수정·커밋을 맡는다.
새 컨텍스트 리뷰어가 기능마다 독립 검토한다.

| 기능 | 사용자 행동과 결과 | 상태 / 의존 |
|---|---|---|
| [F-01](features/f-01-issue-id/plan.md) | 발급 요청 후 ID와 복원 필드 확인 | 승인 대기·D-02~07 미확정으로 차단 |
| F-02 | 발급 불가 오류와 회복 동작 확인 | 계획 예정 / F-01 |
| F-03 | 동시 발급에서 중복 없는 결과 확인 | 계획 예정 / F-02 |
| F-04 | 다른 워커의 두 서버에서 ID 발급 | 계획 예정 / F-03 |

F-01부터 정확성에 필요한 오류 처리·잠금을 포함한다.
F-02·03은 외부 시나리오와 검증을 확장한다. 필수 안전장치를 뒤로 미루지 않는다.
기능 계획·검증·리뷰 형식은 [features](features/README.md)를 따른다.
D-02~07의 영향 범위는 현재 F 번호로 연결한다.
