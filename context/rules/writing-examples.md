# 표현 예시

[설명과 문서 작성 지침](explanation-and-documentation.md)을 적용한 예시입니다.
아래 상황과 검증 결과는 설명을 위한 예시이며, 현재 Snowflake 프로젝트의 구현·검증 사실이 아닙니다.
실제 보고에서는 확인한 동작과 실행한 검증 결과만 작성합니다.

## 인증 변경

> 액세스 토큰이 만료되면 갱신을 한 번 시도하도록 변경했습니다.
> 갱신에 실패하면 로그인 화면으로 이동합니다.
> 갱신 성공·실패 테스트는 통과했지만, 모바일 실기기에서는 아직 확인하지 못했습니다.

## 캐시 적용

> 단어 목록 조회 결과를 30초 동안 캐시에 저장하도록 변경했습니다.
> 같은 사용자의 반복 요청에서 DB 조회를 줄이려는 목적입니다.
> 캐시 무효화가 없으면 수정한 내용이 최대 30초 늦게 보일 수 있습니다.
> 응답 시간은 아직 측정하지 않았습니다.

## 코드 구조 변경

> 화면 컴포넌트에 있던 API 호출과 응답 변환 코드를 wordsApi.ts로 옮겼습니다.
> 서버 응답 형식이 바뀔 때 수정할 코드를 한곳에 모으려는 목적입니다.
