# F-01 독립 리뷰

상태: 미실행. 검토할 구현 diff가 없다.

## 리뷰 대상
리뷰어 / 새 컨텍스트 여부 / 승인 계획 / 기준 커밋 / 대상 diff: 미지정.
새 파일과 미커밋 변경을 포함하고 검토 대상 소스를 식별한다.

## 발견 사항
아직 검토하지 않았다. 발견 사항이 없다는 판정이 아니다.
검토 시 ID·심각도·파일/줄·문제·근거·기대 동작·차단 여부를 기록한다.

## 수정과 재검토
발견 사항별 수정 위치, 재검증 명령과 결과, 재검토 판정을 연결한다.
리뷰어는 코드를 수정하지 않으며 메인 에이전트가 수정한다.

## 최종 판정
검증 보류. 독립 리뷰 및 구현 검증이 수행되지 않았다.
