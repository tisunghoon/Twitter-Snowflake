## 과거 기록: 사전 준비·계획 검수·제품 리뷰와 수정 이력

아래는 각 단계 당시의 원문입니다. 미실행·승인 대기·수정 필요·재검토 대기 표현은 당시 상태이며 현재 판정이 아닙니다. 사실·근거·세션·커밋·로그를 보존합니다.

상태: 미실행. 검토할 구현 diff가 없다.

### 리뷰 대상
리뷰어 / 새 컨텍스트 여부 / 승인 계획 / 기준 커밋 / 대상 diff: 미지정.
새 파일과 미커밋 변경을 포함하고 검토 대상 소스를 식별한다.

### 발견 사항
아직 검토하지 않았다. 발견 사항이 없다는 판정이 아니다.
검토 시 ID·심각도·파일/줄·문제·근거·기대 동작·차단 여부를 기록한다.

### 수정과 재검토
발견 사항별 수정 위치, 재검증 명령과 결과, 재검토 판정을 연결한다.
리뷰어는 코드를 수정하지 않으며 메인 에이전트가 수정한다.

### 최종 판정
검증 보류. 독립 리뷰 및 구현 검증이 수행되지 않았다.

### 2026-11-12 재작성 계획 사전 검토
새 컨텍스트 `/root/f01_plan_review` (`fork_turns=none`)가 계획·설계·결정을 읽기 전용 검토했습니다. JDK 21 접두어 누락과 AC-06 실패 재현 절차 누락(P2 2건)을 보고했습니다. 메인 담당이 모든 예정 Gradle 명령에 JDK 21을 명시하고 워커 오류·HTTP 실패·포트 점유 재현 및 기존 리스너 생존 확인 절차를 추가했습니다. 이 기록은 계획 검토이며 제품 독립 리뷰는 여전히 미실행입니다.

### 2패널 Codex 계획 검수
사용자 요청으로 Herdr `wG:p2` Codex(세션 `01a1cdcf-4b50-7e41-9d8a-a63b346c1691`)에 읽기 전용 계획 검수를 요청했습니다. 화면에서 소진 후 반복 오류·상태 유지 검증 부족과 TCP 준비 판정의 runtime-checks.md 충돌을 확인했습니다. 메인 담당이 설계·실행 명세와 대조해 AC-04에 반복 소진·역행 복귀 후 소진 검사를 추가하고 준비 판정을 실제 POST의 200·JSON 확인으로 수정했습니다. 정식 회신은 P2 R-01·R-02 두 건, P0/P1 없음입니다. 원 검토 계획 SHA256은 `3ae220e14d7d7303167034e17592d54cac057dbd7d529d0951251fc143470438`입니다. 최소 2회 연속 소진 오류와 자식 프로세스 생존 확인까지 명시하고 재검수를 요청합니다. 제품 독립 리뷰를 대체하지 않습니다.

#### 2패널 재검수 결과
`wG:p2`가 수정된 계획을 직접 읽고 R-01/R-02 모두 해소로 판정했습니다. 검토 SHA256: `64047624fbbe2e6724ef6856928f8ddac309616decf8aaafc18f1c783541edb3`. 이번 두 지적에 대한 동료 계획 재검수 통과이며 추가 차단 문제는 발견하지 못했습니다. 문서 수정·제품 테스트는 리뷰어가 수행하지 않았으며, 설계 승인과 새 컨텍스트 독립 제품 리뷰를 대체하지 않습니다.

### 독립 제품 리뷰
새 컨텍스트 `/root/f01_product_review` (`fork_turns=none`)가 기준 e154684 이후 새 파일 포함 제품 코드·테스트·빌드·스크립트·실행 증거를 읽기 전용 검토했습니다.
- R-01/P2/차단: 임시 포트 검사 후 타 서버 선점 시 타 서버의 정상 응답으로 스모크 거짓 성공. 리뷰어가 직접 실제 경합을 재현했습니다.
- AC-01~05는 근거 충족, 추가 core/API/설정 결함 발견 없음. 리뷰어 직접 Gradle JUnit 13건 통과.
- 메인 수정: 자식 전용 로그의 정확한 포트 기동 완료와 애플리케이션 시작 완료 확인 후 HTTP 검사, 요청 전후 생존 확인, 포트 경쟁 회귀 검사 추가.
- 검증: 수정 전 회귀 exit1 → 수정 후 전체 verify exit0, `build/verification/20261112-132131/verify.log`. 재리뷰 대기 중입니다.
