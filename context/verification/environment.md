# 실행 환경

## 현재 상태
2026-11-12 F-01: Java 21.0.11·Boot 4.1.2·Gradle 8.14.7을 실행했습니다.
JSON·HTTP 검사는 Python 3.10 이상 표준 라이브러리를 사용합니다. CI는 미구축입니다.

## 목적
로컬과 CI에서 같은 JVM과 빌드 도구로 검증한다.

## 사전 조건
모든 명령은 저장소 루트에서 실행한다.
필요 도구는 JDK, Git, HTTP 요청 도구, JSON 응답 검사 도구다.
검증용 Python 3.10 이상이 필요하며 doctor에서 버전을 확인합니다.
Gradle은 전역 설치본 대신 저장소의 Wrapper를 사용한다.

## 실행 방법
현재 설치 상태를 읽는 명령은 다음과 같다. 출력만으로 버전 적합성을 확정하지 않는다.

```sh
java -version
git --version
```

`./scripts/doctor.sh`는 JVM·Python을 검사합니다. 포트 선점은 smoke_test.py에서, 필수 워커 설정은 설정 테스트·서버 시작에서 검사합니다.
`./gradlew --version`의 JVM도 확인한다. 셸의 Java와 Gradle JVM은 다를 수 있다.
`JAVA_HOME`은 확정된 JDK 설치 경로를 사용하며 개인 경로를 공통 설정에 하드코딩하지 않는다.
`snowflake.worker-id`는 실행마다 명시하고 두 프로세스에는 서로 다른 값과 포트를 배정한다.
확정된 워커 범위는 0~1023이며 기본값은 두지 않는다.

## 성공 기준과 실패 시 확인
확정 버전과 실제 JVM이 일치하고 필요한 도구와 설정이 모두 있어야 한다.
검사 실패 시 누락 항목과 해결 방법을 출력하고 종료한다. 도구를 몰래 설치하지 않는다.
포트가 사용 중이면 다른 검증용 포트를 선택한다. 기존 프로세스를 종료하지 않는다.

## 정리 방법
점검 단계는 서버를 시작하거나 영구 환경 설정을 바꾸지 않는다.
검증 과정에서 설정한 환경 변수는 해당 프로세스 범위로 제한한다.
