# 기능별 작업 목록

메인 담당은 Herdr 구현 담당 Agy(wG:p3)입니다. 전달 시 현재 세션을 확인합니다.
사용자가 F-01~04 작업 착수와 인계를 요청했습니다. 상세 계획과 D-02~07의 상태를 확인한 뒤 진행합니다.
기능 하나의 검증·새 컨텍스트 독립 리뷰·커밋을 마친 다음 기능으로 이동합니다.

| 기능 | 사용자 행동과 결과 | 상태 / 의존 |
|---|---|---|
| [F-01](features/f-01-issue-id/plan.md) | 발급 요청 후 ID와 복원 필드 확인 | 작업 요청 수신, 상세 계획·미정 설계 확인 |
| [F-02](features/f-02-error-recovery/plan.md) | 발급 불가 오류와 회복 동작 확인 | 계획 작성 / F-01 |
| [F-03](features/f-03-concurrent-issuance/plan.md) | 동시 발급에서 중복 없는 결과 확인 | 계획 작성 / F-02 |
| [F-04](features/f-04-multi-worker/plan.md) | 다른 워커의 두 서버에서 ID 발급 | 계획 작성 / F-03 |

F-01부터 정확성에 필요한 오류 처리·잠금을 포함합니다.
F-02·03은 외부 시나리오와 검증을 확장하며 필수 보호를 뒤로 미루지 않습니다.
기능별 계획·검증·리뷰 형식은 [features](features/README.md)를 따릅니다.
