## 현재 운영 기준
기능별 계획 → 구현 → 자체 검증 → 독립 리뷰 → 수정·재검증·커밋을 따른다.
이슈 실행 규칙과 templates, features의 계획·검증·리뷰 형식을 사용한다.
이번 ECC 분석은 규칙 개선 요청이며 F-01 구현·배포 승인이 아니다.

## ECC 비교와 동료 논의
같은 Herdr 탭 Claude(wG:p1)와 ECC 원문 및 현재 문서를 읽기 전용으로 비교했다.
테스트 우선, 구체적인 리뷰 근거, 단계별 문서 로딩, 최신 재개 블록을 채택했다.
F-02부터 기존 회귀 기준선을 기록한다. F-01에는 기존 구현 기준선이 없다.
ECC 전체 설치·자동 학습·훅 프로필 런타임 도입은 하지 않았다.
검증 문서의 예정 명령과 실제 실행 환경을 구분한다. 실제 구축이 다음 우선 과제다.
