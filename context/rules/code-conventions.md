# 코드 컨벤션

앞으로 작성할 Java 코드와 문서의 표기 기준이다. 자동 포매터는 아직 선정하지 않았다.
Java·Spring Boot·Gradle의 구체적인 버전은 [결정 기록](../decisions.md)의 확정 상태를 따른다.
학습 노트에 사용했던 Java 17 기준을 이 프로젝트에 가져오지 않는다.

## 파일과 이름

| 대상 | 규칙 | 예시 |
|---|---|---|
| Java 클래스·record | PascalCase | `SnowflakeGenerator`, `IdResponse` |
| 메서드·변수 | camelCase | `nextId`, `elapsedMillis` |
| 상수 | UPPER_SNAKE_CASE | `SEQUENCE_BITS`, `MAX_WORKER_ID` |
| 패키지 | 소문자 | `core`, `api`, `config` |
| Markdown 파일 | 영문 소문자, 단어 사이 하이픈 | `design-patterns.md` |

공개 최상위 타입은 같은 이름의 Java 파일에 둔다.
테스트 클래스는 대상 이름 뒤에 `Test`를 붙이고 테스트 패키지는 대상 패키지와 맞춘다.
테스트 메서드는 `rejectsClockRollback`처럼 행동을 이름으로 적는다.

## 배치와 서식

- UTF-8, LF 줄바꿈, 파일 끝 개행을 사용한다.
- Java 들여쓰기는 공백 4칸으로 통일한다. 탭과 섞지 않는다.
- 여는 중괄호는 선언과 같은 줄에 두고, 한 줄 조건문에도 중괄호를 쓴다.
- 한 줄은 120자를 기준으로 나눈다. 긴 URL은 예외로 둔다.
- import는 명시적으로 작성한다. 일반 import와 static import를 빈 줄로 구분한다.
- 의존 객체는 생성자로 받는다. 필드 주입은 사용하지 않는다.
- 외부에서 바꾸면 안 되는 필드는 `private final`로 선언한다.

## 숫자·시간·응답

ID와 밀리초 시각은 `long`으로 다룬다. 큰 비트 마스크는 `1L`을 사용해 계산한다.
워커 값을 시프트할 때에는 먼저 `long`으로 변환한다.
비트 결합에는 괄호를 써서 시간·워커·순번의 경계를 드러낸다.
시간은 주입한 `Clock`에서 읽고, 응답의 시간은 생성된 ID에서 복원한다.
현재 설계의 JSON `id`는 십진 문자열이며, 내부 계산 타입은 `long`이다.
이 계약을 바꾸면 설계·API 테스트·문서를 함께 수정한다.

## 테스트와 설명

테스트는 준비 → 실행 → 검증 순서로 작성한다.
시간 경계 테스트는 제어 가능한 Clock으로 재현한다. 실제 `sleep`으로 시각을 맞추지 않는다.
동시성 테스트는 모든 Future의 결과를 확인하고 종료 제한과 자원 정리를 둔다.
응답 도착 순서를 ID 생성 순서로 간주하지 않는다.

설명과 주석은 한국어로 작성한다. 기술 용어는 첫 등장에 괄호로 뜻을 풀어 쓴다.
메서드·클래스 이름은 설명에 맞춰 번역하지 않고 실제 영문 이름을 유지한다.
