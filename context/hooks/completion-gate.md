# 완료 게이트

## 식별과 상태
- 훅 ID: H-04
- 정책 버전: 0.1
- 상태: 명세 작성 / 스크립트 미구축 / 호스트 미연결
- 아래 시간·명령은 구축 기준이며 실제 작동을 검증한 값이 아니다.

## 실행 시점
기능 완료 선언 전 또는 이를 지원하는 호스트 종료 이벤트에서 검사한다.
일반 질문·계획 제시·진행 보고·사용자 중단 요청에는 완료 판정을 적용하지 않는다.

## 적용 범위
현재 기능의 최종 변경, 필수 검증 결과, 독립 리뷰, 미해결 차단 결함을 확인한다.
완료 여부를 검사하며 테스트 실행·자동 커밋·push·배포를 수행하지 않는다.

## 입력과 증거
기능 단계·승인 계획·AC, 실행기가 생성한 검사 결과와 관련 입력의 내용 해시를 받는다.
새 파일·미커밋 변경도 해시에 포함한다. 커밋 번호만으로 소스 일치를 판단하지 않는다.
독립 리뷰의 세션 식별·대상 diff·판정과 수정 후 재검토 결과를 확인한다.
결과 기록의 보관·변경 권한을 제한하며 AI가 수정할 수 있는 JSON만으로 강한 위변조 방지를 주장하지 않는다.

## 검사 명령
예정: `./scripts/hooks/check-completion`.
기존 증거를 확인하며 전체 테스트를 다시 실행하지 않는다.
호스트별 종료 차단·재진입·검증 차단 보고 응답은 연결 전에 시험한다.

## 판정 기준
최종 입력에 맞는 필수 검증 결과 없음, 실패·미실행·시간 초과, 독립 리뷰 누락,
차단 결함 미해결, 리뷰 대상과 최종 변경 불일치가 있으면 완료 불가다.
미실행 사유를 보고했다고 필수 검증이 통과한 것은 아니다.

## 실패 동작
완료 선언을 차단하고 수정·재검증 또는 독립 리뷰로 돌려보낸다.
환경 문제로 해결할 수 없으면 완료가 아닌 검증 차단 상태로 보고하도록 허용한다.
리뷰어 부재·필수 검사 미실행은 기존 워크플로우의 검증 보류 상태에 해당한다.

## 시간 제한
결과 확인 최대 2초. 같은 기능·변경 상태에서 자동 복귀는 최대 2회다.
그 이후 검증 차단 사유와 필요한 다음 행동을 보고한다. 종료 이벤트 재호출로 횟수를 초기화하지 않는다.

## 예외 처리
사용자 중단과 검증 차단 보고는 허용한다. 완료 기준을 우회한 성공 보고는 허용하지 않는다.
문서 전용 작업은 승인된 문서 검사 증거를 사용하며 제품 테스트 통과로 표현하지 않는다.

## 출력 정책
부족하거나 오래된 증거, 실패 검사 ID, 다음 행동을 짧게 출력한다.
비밀 값과 전체 명령·로그를 재출력하지 않는다.

## 검사기 오류 처리
검사기 누락·오류·시간 초과는 완료 불가다. 차단 사유 보고는 허용한다.
호스트가 종료 차단을 지원하지 않으면 알림 또는 명시적 게이트로 표시하고 강제 차단으로 표현하지 않는다.

## 재검사 조건
관련 코드·설정·검증 정책·필수 검사 목록이 바뀌면 기존 증거를 재평가한다.
리뷰 후 정확성에 영향을 주는 변경은 재리뷰하고 새 결과로 완료 판정을 다시 수행한다.
