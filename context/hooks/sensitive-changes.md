# 민감한 변경 감지

## 식별과 상태
- 훅 ID: H-02
- 정책 버전: 0.1
- 상태: 명세 작성 / 스크립트 미구축 / 호스트 미연결
- 아래 시간·명령은 구축 기준이며 실제 작동을 검증한 값이 아니다.

## 실행 시점
보호 파일 수정 전, 기능 작업 단위 종료 시, 커밋 전에 검사한다.
사전 이벤트가 없는 도구에서는 사후 감지와 커밋 차단만 가능하다고 표시한다.

## 적용 범위
`.env` 계열·인증서·키 파일, 에이전트 지침·권한·훅 설정, `.github/workflows/`,
빌드·의존성·잠금 파일과 검증 제외 설정을 대상으로 한다. 인증 코드 변경은 리뷰 대상으로 표시한다.
DB 도입 전에는 적용된 마이그레이션 검사를 활성화하지 않는다.

## 입력과 증거
기준 버전, 변경 전후 파일 목록, 새 파일·삭제·이름 변경, 스테이징 내용을 확인한다.
훅·권한 변경은 변경 전의 검토된 정책으로 검사한다.
의존성 변경 이유·대안·승인 계획과 민감 변경의 독립 리뷰 기록을 연결한다.

## 검사 명령
예정: `./scripts/hooks/check-sensitive-changes`.
작업 변경과 커밋 대상 검사는 구분한다. 인자와 비밀정보 검사 도구는 구현 시 확정한다.
실제 비밀 값을 탐지하기 위한 읽기는 출력·전송 허용을 의미하지 않는다.

## 판정 기준
비밀 값이 커밋 대상에 포함되면 실패다. 예제 파일도 실제 값이 있으면 실패다.
훅·권한·CI·검증 비활성화 변경은 별도 리뷰 필요로 표시하고 미검토 시 완료·커밋을 막는다.
의존성 변경 이유·대안이 없거나 필요한 잠금 파일이 불일치하면 수정 필요다.
추후 적용 이력이 확인된 마이그레이션 수정은 차단한다. 파일명만으로 적용 여부를 추정하지 않는다.

## 실패 동작
비밀 값의 커밋은 차단한다. 값을 제거하고 필요하면 노출 대응을 안내한다.
민감 변경은 사용자 변경을 자동으로 되돌리지 않고 메인 담당의 수정·독립 리뷰·재검증을 요구한다.

## 시간 제한
최대 5초. 자동 재시도 0회.
대상 축소나 설정 수정 후 새 검사로 실행하며 전체 검사 누락을 통과로 처리하지 않는다.

## 예외 처리
값이 없는 예제·검증된 테스트용 가짜 값만 경로와 사유를 좁게 지정해 제외할 수 있다.
파일 확장자나 예제 파일명만으로 전체 내용을 면제하지 않는다.
실제 비밀 값의 커밋을 일반적인 우회 승인으로 허용하지 않는다.

## 출력 정책
파일 경로, 검사 종류, 발견 개수, 리뷰 필요 사유와 다음 행동을 출력한다.
비밀 값과 그 값이 포함된 원본 줄은 출력하지 않는다. 저장 로그에도 동일하게 적용한다.

## 검사기 오류 처리
누락·오류·시간 초과는 검사 불가다. 해당 민감 변경의 커밋·완료를 보류한다.
진단 실패를 비밀 값이 없다는 결과로 기록하지 않는다.

## 재검사 조건
파일 내용·스테이징·정책·잠금 파일이 바뀌면 재검사한다.
리뷰 후 민감 변경이 추가되면 새 diff를 다시 리뷰한다.
